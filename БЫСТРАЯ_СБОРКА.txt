1️⃣  ПРОВЕРИТЬ RUST TOOLCHAIN:
   rustup default stable-x86_64-pc-windows-gnu

2️⃣  ПЕРЕЙТИ В ПАПКУ ПРИЛОЖЕНИЯ:
   cd notes-backend/guest-app

3️⃣  УСТАНОВИТЬ ЗАВИСИМОСТИ (если нужно):
   npm install

4️⃣  СОБРАТЬ ПРИЛОЖЕНИЕ:
   npm run tauri:build

5️⃣  СКОПИРОВАТЬ НА РАБОЧИЙ СТОЛ:
   Copy-Item "src-tauri\target\release\guest-app.exe" "$env:USERPROFILE\Desktop\guest-app.exe"

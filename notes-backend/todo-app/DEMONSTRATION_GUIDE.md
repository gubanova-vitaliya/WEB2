## 📐 ЧАСТЬ 3: АДАПТИВНОСТЬ И RESPONSIVE DESIGN

### Шаг 5: Демонстрация адаптивности в браузере

1. **Откройте приложение в браузере на компьютере:**
   ```
   https://gubanova-vitaliya.github.io/WEB2/
   ```

2. **Включите режим разработчика:**
   - Нажмите **F12** или **Ctrl+Shift+I**
   - Нажмите иконку **"Toggle device toolbar"** (📱)

3. **Тестирование разных разрешений:**

   **Desktop (1200px+):**
   - Установите ширину: **1200px**
   - **Результат:** 
     - Навигация: горизонтальная, все ссылки видны
     - Карточки задач: **3-4 колонки**
     - Размер карточек: **300px ширина**
     - Галерея: **3 колонки** изображений

   **Tablet (768px-1199px):**
   - Установите ширину: **768px**
   - **Результат:**
     - Навигация: компактная, меньше отступов
     - Карточки задач: **2 колонки**
     - Размер карточек: **45% ширины контейнера**
     - Галерея: **2 колонки** изображений

   **Mobile (до 767px):**
   - Установите ширину: **375px** (iPhone)
   - **Результат:**
     - Навигация: **burger menu** (гамбургер)
     - Карточки задач: **1 колонка**
     - Размер карточек: **100% ширины**
     - Галерея: **1 колонка** изображений

## 🖥️ ЧАСТЬ 4: TAURI И ПОДКЛЮЧЕНИЕ К API ПО IP

### Шаг 7: Настройка IP адреса для локальной сети

1. **Узнайте IP адрес компьютера:**
   ```bash
   # Windows
   ipconfig
   # Найдите IPv4 адрес (например: 192.168.1.105)
   
   # macOS/Linux  
   ifconfig
   # Найдите inet адрес
   ```

2. **Обновите конфигурацию API:**
   ```javascript
   // Файл: src/config/api.js
   const API_CONFIG = {
     tauri: {
       baseURL: 'http://192.168.1.105:3000', // ВАШ IP
       timeout: 10000
     }
   };
   ```

### Шаг 8: Запуск backend с логированием IP

1. **Запустите backend:**
   ```bash
   cd notes-backend
   node index.js
   ```

2. **Проверьте вывод в консоли:**
   ```
   Сервер запущен на порту 3000
   Доступен по адресу: http://192.168.1.105:3000
   ```

### Шаг 9: Запуск Tauri приложения

1. **Запустите Tauri:**
   ```bash
   cd notes-backend/todo-app
   npm run tauri dev
   ```

2. **Проверьте подключение:**
   - Откройте DevTools в Tauri (ПКМ → Inspect)
   - В консоли должно быть: `API Mode: tauri`
   - Проверьте Network tab при загрузке данных

### Шаг 10: Сравнение IP в коде и консоли

**Покажите в коде:**
```javascript
// src/config/api.js - строка 16
baseURL: 'http://192.168.1.105:3000'
```

**Покажите в консоли backend:**
```
Сервер запущен на порту 3000
GET /todos 200 - 2.345 ms
```

**Покажите в Tauri DevTools:**
```
API Mode: tauri {baseURL: "http://192.168.1.105:3000"}
```

### Шаг 11: Демонстрация редактирования данных

1. **Добавьте задачу в Tauri приложении:**
   - Заполните поля "Название" и "Содержание"
   - Нажмите "Добавить"

2. **Проверьте в консоли backend:**

## 🔒 ЧАСТЬ 5: НАСТРОЙКА HTTPS

### Шаг 12: Генерация SSL сертификатов

1. **Установите mkcert (если не установлен):**
   ```bash
   # Windows (через Chocolatey)
   choco install mkcert
   
   # macOS
   brew install mkcert
   
   # Linux
   sudo apt install mkcert
   ```

2. **Создайте локальный CA:**
   ```bash
   mkcert -install
   ```

3. **Генерируйте сертификаты:**
   ```bash
   cd notes-backend/todo-app
   mkcert localhost 127.0.0.1 192.168.1.105
   # Создаст: localhost+2.pem и localhost+2-key.pem
   ```

4. **Переименуйте файлы:**
   ```bash
   mv localhost+2.pem cert.crt
   mv localhost+2-key.pem cert.key
   ```

### Шаг 13: Проверка HTTPS конфигурации

1. **Проверьте vite.config.js:**
   ```javascript
   server: {
     port: 3001,
     https: fs.existsSync(path.resolve('cert.key')) ? {
       key: fs.readFileSync(path.resolve('cert.key')),
       cert: fs.readFileSync(path.resolve('cert.crt')),
     } : undefined,
   }
   ```

2. **Запустите с HTTPS:**
   ```bash
   npm run dev
   ```

3. **Откройте в браузере:**
   ```
   https://localhost:3001
   https://192.168.1.105:3001
   ```

4. **Проверьте PWA функции:**
   - Service Worker работает только с HTTPS
   - Установка PWA доступна только с HTTPS
   - Push уведомления требуют HTTPS

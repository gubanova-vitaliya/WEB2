# 🖥️ Как собрать десктопное Tauri приложение с газами

## 📋 Пошаговая инструкция

### Шаг 1: Проверить установку Rust

```powershell
rustc --version
cargo --version
```

Если не установлено, скачайте с [rustup.rs](https://rustup.rs/)

### Шаг 2: Убедиться, что используется правильный toolchain

```powershell
rustup default stable-x86_64-pc-windows-gnu
rustup show
```

**Важно:** Если у вас нет Visual Studio Build Tools, используйте GNU toolchain (как показано выше).

### Шаг 3: Перейти в папку приложения

```powershell
cd notes-backend/guest-app
```

### Шаг 4: Установить зависимости (если еще не установлены)

```powershell
npm install
```

### Шаг 5: Собрать приложение

```powershell
npm run tauri:build
```

⏳ **Первая сборка может занять 10-20 минут** (компиляция Rust зависимостей)

### Шаг 6: Найти готовый .exe файл

После успешной сборки файл будет здесь:
```
notes-backend/guest-app/src-tauri/target/release/guest-app.exe
```

### Шаг 7: Скопировать на рабочий стол

#### Способ 1: Вручную
1. Найдите файл `guest-app.exe` в папке `target/release/`
2. Скопируйте его (Ctrl+C)
3. Вставьте на рабочий стол (Ctrl+V)

#### Способ 2: Через PowerShell (автоматически)
```powershell
Copy-Item "src-tauri\target\release\guest-app.exe" "$env:USERPROFILE\Desktop\guest-app.exe"
```

#### Способ 3: Использовать готовый скрипт
```powershell
cd ..\..\..
.\build-and-copy-to-desktop.ps1
```

## ⚡ Быстрая команда (все в одной строке)

```powershell
cd notes-backend/guest-app; npm run tauri:build; Copy-Item "src-tauri\target\release\guest-app.exe" "$env:USERPROFILE\Desktop\guest-app.exe"
```

## 🔧 Если возникают ошибки

### Ошибка: `linker 'link.exe' not found`

**Решение:** Используйте GNU toolchain:
```powershell
rustup default stable-x86_64-pc-windows-gnu
```

Или установите Visual Studio Build Tools (см. `FIX_RUST_BUILD_ERROR.md`)

### Ошибка: `gcc.exe not found`

**Решение:** Установите MinGW-w64:
- Скачайте с [mingw-w64.org](https://www.mingw-w64.org/downloads/)
- Или установите через MSYS2: `pacman -S mingw-w64-x86_64-gcc`

### Очистка кэша сборки

Если сборка зависла или есть ошибки:
```powershell
cd notes-backend/guest-app/src-tauri
cargo clean
cd ..
npm run tauri:build
```

## 📝 Важные замечания

- ✅ **Размер файла:** Обычно 5-15 МБ
- ✅ **Установка не требуется:** Просто запустите `.exe` файл
- ✅ **Портативность:** Можно скопировать на другой компьютер с Windows
- ⚠️ **Первая сборка:** Занимает много времени (10-20 минут)
- ⚠️ **Последующие сборки:** Быстрее (1-2 минуты)

## 🚀 Запуск приложения

Просто дважды кликните на `guest-app.exe` на рабочем столе!

## 📦 Альтернатива: Создать установщик

Tauri автоматически создает установщик в папке:
```
notes-backend/guest-app/src-tauri/target/release/bundle/msi/
```

Там будет файл `.msi` для установки приложения.

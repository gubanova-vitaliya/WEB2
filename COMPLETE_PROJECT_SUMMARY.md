## 🎯 **Режимы работы**

### 1. **Development** (локальная разработка)
```bash
# Backend
cd notes-backend && node index.js

# Frontend
cd notes-backend/todo-app && npm run dev
```
- **Frontend**: `https://localhost:3001` (HTTPS с сертификатами)
- **Backend**: `http://localhost:3000`
- **PWA**: работает в dev режиме

### 2. **Tauri Desktop** (нативное приложение)
```bash
cd notes-backend/todo-app
npm run tauri:dev    # Разработка
npm run tauri:build  # Сборка
```
- **API**: подключение по IP в локальной сети
- **Возможности**: нативные диалоги, меню, события

### 3. **GitHub Pages** (веб PWA)
```bash
npm run deploy
```
- **URL**: `https://username.github.io/RIP/`
- **PWA**: установка на мобильные устройства
- **Mock данные**: для демонстрации без backend
